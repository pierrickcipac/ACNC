# Objectif Ligne — programme de formation pilote

Application web autonome (un seul fichier `index.html`) : bilan & aptitudes, brevet ULM, licence PPL(A), ATPL théorique.
Cours illustrés (schémas SVG), quiz expliqués, examens blancs, révision des erreurs, bilan d'aptitude, calcul mental chrono, barre de progression.

- `src/` : sources (`app.html`, `figures.js`, `data-*.js`, format décrit dans `SCHEMA.md`)
- `node build.js` : régénère `index.html` à partir de `src/`
